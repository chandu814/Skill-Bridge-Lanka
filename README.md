Skill Bridge Lanka

Skill Bridge Lanka is a web-based career readiness platform developed for Sri Lankan IT undergraduate students. The system helps students assess technical skills, identify skill gaps, explore learning resources, track progress, and receive professional IT career counselling.

🚀 Features
User Registration & Profile Management
Skill Assessment System
Learning Resource Suggestions
Job Market Information & Progress Tracking
Premium IT Career Counselling Service
🛠️ Technologies Used
React.js
Spring Boot
MySQL
GitHub
Postman
⚙️ Setup
git clone https://github.com/your-username/skill-bridge-lanka.git

Configure application.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/skillbridge_db?createDatabaseIfNotExist=true
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
spring.jpa.hibernate.ddl-auto=update

Run Backend and Frontend separately.
